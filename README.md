# Taller-Estructuras-Lineales

**Estudiante:** Julian Aldemar Perez Elvira

## Descripción
Taller de estructuras lineales en Java que cubre tres tipos de datos:

- **Arreglos unidimensionales**: generación de datos aleatorios, números primos y pares, factoriales, búsqueda de mínimos/máximos e inversión de valores.
- **ArrayList**: inserción ordenada, eliminación de elementos, cálculo de frecuencias, ordenamiento y separación de valores, y el ejercicio de partidos de fútbol.
- **Matrices**: búsqueda de elementos, cálculo de diagonales, verificación de simetría, transposición e intercambio de filas.

El proyecto está desarrollado con enfoque en Clean Code y programación orientada a objetos, separando en cada ejercicio la generación de datos, el procesamiento y la impresión de resultados.

## Estructura del proyecto

- `src/arreglos/` — ejercicios de arreglos unidimensionales
- `src/arraylist/` — ejercicios con ArrayList
- `src/matrices/` — ejercicios de matrices

## Cómo ejecutar
1. Clonar el repositorio:

git clone https://github.com/Julian0327/Taller-Estructuras-Lineales.git

2. Abrir el proyecto en NetBeans o VS Code.
3. Ubicar la clase `Main.java` dentro de `src/`.
4. Ejecutar el programa con el botón **Run** del editor sobre la clase `Main`.
5. Seguir las instrucciones que aparecen en consola para cada ejercicio.
